# Product overview — Kubernetes Dashboard Glass UI v1

This document is the short product summary. Full operations and install steps live in the root [README.md](../README.md).

## Positioning

**kubernetes-dashboard Glass UI v1** is a presentation layer for the stock Kubernetes Dashboard: frosted-glass visuals suitable for demos and lab clusters, installed beside—not instead of—the upstream Dashboard.

## Deliverables

- Installable manifests (`deploy/`)
- Automation scripts (`scripts/`)
- Theme asset (`glass-theme.css`)
- Operator documentation (`README.md`)

## Support model

Community / lab packaging. Validate against your cluster security policy before production use.
